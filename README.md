# VLSI CAD Projects

This repository collects my course projects in VLSI physical design automation, with an emphasis on algorithm design for floorplanning and placement legalization.

## Projects

- **HW3: Fixed-outline Floorplan Design**  
  Implemented a simulated annealing-based approach for hard-block floorplanning to optimize wirelength under fixed-outline and dead-space constraints.

- **HW4: Standard-Cell Placement Legalization**  
  Implemented an Abacus-based legalization approach to map cells onto legal rows and sites while minimizing displacement and removing overlaps.

## Skills Demonstrated

- C++
- Simulated annealing
- Abacus legalization
- Floorplanning and placement algorithms
- Physical design optimization
- Constraint-aware objective design
- Performance and solution-quality analysis
